- 関数スコープ（function scope）
- name にアクセスできるのはその関数内のみ
- 即時実行関数（IIFE）：関数を定義した直後に実行できる便利なデザインパターン
- 変数に対して別のスコープを作成することで、グローバル名前空間が汚染されるのを防げる
- IIFE の定義に関しては複数の方法がある

1. 従来の丸括弧で囲む方法

```javascript:index.js
(function() {
  //関数本体
})();

//アロー関数でも示せる
(() => {
//関数本体
})();
```

2.単項演算子で囲む方法

```javascript:index.js
!function(){
//関数本体
}();
```

IIFE の前に論理否定演算子を追加する
!は「この関数をすぐに実行せよ」の略号のようなもの

3.グループ化演算子で囲む方法

```javascript:index.js
(function() {
  //関数本体
}());
```

4.関数宣言を囲む方法
```javascript:index.js
(function namedIIFE() {

})();
```
